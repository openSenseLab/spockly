# spockly

A Blockly-based React + Vite starter with a standard Blockly workspace and live Python
preview.

## Stack

- React 19
- Vite 8
- Blockly 13
- Zustand 5
- Radix UI Themes

## Scripts

- `npm run dev` – start the Vite development server
- `npm run build` – build the production bundle
- `npm run lint` – run oxlint
